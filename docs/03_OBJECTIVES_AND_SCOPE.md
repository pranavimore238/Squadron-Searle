# Objectives, scope, and expected outcomes

## General objective

To design and implement an interactive educational website that explains John Searle's Chinese Room thought experiment and helps learners examine the distinction between syntax and semantics.

## Specific objectives

1. Summarize the original argument in clear, properly attributed language.
2. Implement a transparent keyword-based simulator that returns deterministic responses to user input.
3. Show which rule matched and provide a fallback for unknown input.
4. Explain syntax, semantics, intentionality, and at least one counterargument.
5. Implement a short multiple-choice quiz with feedback and reset behavior.
6. Create a responsive and keyboard-operable interface.
7. Document local execution, testing, limitations, and optional GitHub Pages deployment.
8. Maintain accurate citations and clearly mark missing institutional requirements.

## Scope included

- Static website and interactive components.
- Browser-only rule-based simulation.
- Explanatory content and a quiz.
- Academic project documentation.
- Test plan and record of tests actually executed.
- README and deployment instructions.

## Out of scope

- Training or fine-tuning an AI model.
- A claim to detect consciousness or genuine understanding.
- Proving or disproving Searle's argument.
- Backend, accounts, database, or analytics.
- A formal user study unless the instructor explicitly requires it and ethical/consent requirements can be met.
- BTU-specific compliance claims without an official rubric or template.

## Expected outcomes

A working educational website, a reproducible code repository, an academic framing package, and documentation sufficient for a reviewer to understand the aim, implementation, and limitations. Actual acceptance remains dependent on the instructor's requirements.
